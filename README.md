# Guy-Line 💬

A modern Flutter-based application designed to provide personalized conversations, life guidance, and user-focused support through a clean and intuitive mobile experience.

The application provides user authentication, personalized onboarding, profile management, conversation features, AI assistant interaction, subscription options, and conversation history.

---

## ✨ Features

### 🔐 Authentication & Account
- User registration and login
- Email/password authentication
- Verification code flow
- Forgot password
- Password reset
- Change password
- Account session management

### 🎯 Personalized Onboarding
- Personalized user onboarding
- Interest selection
- Thinking-style selection
- User preference setup
- Onboarding data submission through REST APIs

### 💬 Conversations & AI Assistant
- Conversation-based user experience
- AI assistant interface
- Message input and interaction
- Conversation categories
- Recent conversations
- Conversation history
- Message timestamps
- Scroll-to-latest-message behavior

### 👤 Profile Management
- User profile
- Edit profile
- Profile image selection
- Account settings
- User information management

### 💳 Subscription & Additional Features
- Subscription section
- Account settings
- Privacy policy
- Terms & conditions
- Custom success and error messages
- Loading states
- Responsive mobile interface
